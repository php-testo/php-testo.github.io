# Testo Plugin Now Available for OpenIDE

Until now, the Testo plugin lived only in JetBrains IDEs. Starting with version `2026.17.262`, it's also on the OpenIDE Marketplace:

<OpenIdePlugin />

[OpenIDE](https://openide.ru/) is a free IDE. The Testo plugin runs on OpenIDE 2026.2 and needs the [PHP plugin](https://marketplace.openide.ru/plugin/php-for-openide/424/) installed.

The OpenIDE build has every feature of the PhpStorm plugin you already know: the code is shared, and only the glue layer differs.

---

Big thanks to Fyodor, who develops the PHP plugin for OpenIDE: the Testo plugin wouldn't run there without it.
