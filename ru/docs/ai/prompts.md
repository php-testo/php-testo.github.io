# Промпты

Готовые промпты для AI-агентов, работающих с Testo. Каждый — это целая задача: подключить фреймворк к проекту, перевести на него существующий набор тестов. Промпт написан так, чтобы агент прошёл его от начала до конца без дополнительных объяснений.

Использовать промпт можно двумя способами. Откройте его страницу и скопируйте текст в чат с агентом — или дайте агенту ссылку на исходный Markdown-файл (адрес с `.md` указан в начале каждой страницы промпта), и он загрузит текст сам. Агенты, которые читают [`llms.txt`](https://php-testo.github.io/llms.txt), найдут тот же список в разделе «Prompts».

Сами промпты — на английском. Так их можно отдать агенту без правок, а код, конфиги и вывод CLI всё равно английские.
