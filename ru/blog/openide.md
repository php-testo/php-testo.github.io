# Плагин Testo теперь в OpenIDE

До сих пор плагин Testo работал только в IDE от JetBrains. С версии `2026.17.262` его можно поставить и из маркетплейса OpenIDE:

<OpenIdePlugin />

[OpenIDE](https://openide.ru/) — бесплатная IDE. Плагин Testo работает в OpenIDE 2026.2, и для него понадобится [PHP-плагин](https://marketplace.openide.ru/plugin/php-for-openide/424/).

Сборка под OpenIDE не уступает по функционалу привычному плагину для PhpStorm: код у них общий, отличается только связующая прослойка.
